# Sherikkon Consulting — редизайн сайта

Статичный сайт на чистом HTML + CSS + GSAP. Никакой сборки: ни Node.js, ни Python,
ни npm install. Открывается двойным кликом и заливается на любой хостинг как есть.

Дизайн-система — **Royal Violet**: тёмная тема, фиолетовый бренд, шампань-золото
как акцент, кинематографические анимации на GSAP ScrollTrigger.

---

## Как посмотреть

**Вариант 1 — просто открыть файл.** Двойной клик по `index.html`. Работает всё,
кроме мелочей, зависящих от протокола (браузер ругнётся на preload шрифтов —
по `file://` это нормально).

**Вариант 2 — локальный сервер (рекомендую).** Правильные MIME-типы, чистая консоль:

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Затем откройте `http://localhost:8080`. Остановить — `Ctrl+C`.
Скрипту нужен только Windows PowerShell.

## Где что менять

### Цвета, шрифты, отступы

Всё в `assets/css/tokens.css`, в блоке `:root`. Меняете переменную — меняется
весь сайт. Ничего искать по файлам не нужно.

| Токен | Значение | Что это |
|---|---|---|
| `--bg` | `#0B0714` | Фон страницы |
| `--surface` / `--surface-2` | `#150E24` / `#1C1330` | Подложки секций и карточек |
| `--primary` | `#7C3AED` | Фиолетовый: ссылки, фокус, интерактив |
| `--accent` | `#D4AF6A` | Шампань-золото: кнопки CTA, цифры, надзаголовки |
| `--fg` / `--fg-muted` | `#F5F3FF` / `#A9A0C4` | Основной и вторичный текст |

**Дисциплина двух акцентов:** фиолетовый — всё интерактивное, золото — премиальный
акцент. Третий акцентный цвет вводить не стоит: именно этим был плох старый сайт,
где рядом жили синий, оранжевый, коралловый и зелёный.

Все пары цветов проверены на контраст: основной текст **18:1**, вторичный **7,2:1**,
золото на фоне **9,6:1**, тёмный текст на золотой кнопке **8,9:1**. Это WCAG AA,
почти везде AAA.

### Скорость и характер анимаций

`--dur-fast`, `--dur`, `--dur-slow` и функции `--ease-*` в том же `tokens.css`.
Сама хореография — в `assets/js/motion.js`.

## ⚠️ Формы пока никуда не отправляются

Это статичный сайт — у него нет сервера, значит сам по себе он данные отправить
не может. Сейчас форма **проверяет поля, показывает состояние отправки и рисует
успех, но заявка никуда не уходит** (в консоль пишется предупреждение с данными,
которые ушли бы на сервер).

**Не выкладывайте сайт в бой, не подключив отправку.**

Чтобы включить: откройте `assets/js/forms.js`, найдите вверху

```js
var ENDPOINT = null;
```

и подставьте адрес обработчика, например Formspree:

```js
var ENDPOINT = 'https://formspree.io/f/ВАШ_ID';
```

Форма отправляет `FormData` методом POST. Подойдёт любой обработчик,
который это принимает: Formspree, Getform, Web3Forms, свой PHP-скрипт
на хостинге или бот в Telegram через прокси. Если нужен другой формат —
меняется только функция `submitLead()`, там же есть готовый пример.

## Что сделано по доступности

- Контраст всех текстовых пар — AA и выше, проверено расчётом.
- Все тач-цели ≥ 44×44 px на мобильном.
- Полная навигация с клавиатуры: видимые фокус-кольца, ловушка фокуса
  в мобильном меню, закрытие по `Esc` с возвратом фокуса на бургер.
- Ошибки форм — под конкретным полем, с `role="alert"`, фокус уходит
  на первое невалидное поле.
- `prefers-reduced-motion` уважается: анимации отключаются, весь контент
  показывается сразу.
- Без JavaScript страница видна полностью (стартовые состояния анимаций
  включаются только при наличии `.js` на `<html>`).
- Логотип, соцсети и иконки-кнопки подписаны через `aria-label`.
- Эмодзи в роли иконок не используются — только SVG.

## Анимации

Все построены на `gsap.matchMedia()` с тремя ветками: reduced-motion,
общая и десктопная (≥1024 px). На мобильных pin-секции и горизонтальная
лента отключаются, лента переходит на обычный свайп со snap.

**Главная:**
1. Прелоадер со шторой — один раз за сессию.
2. Заголовок героя разбивается на слова (SplitText) и выезжает из маски.
3. Аврора на фоне медленно дрейфует и реагирует на движение мыши.
4. Полоса прогресса скролла вверху.
5. Секция «Проблема» пинится, три боли сменяют друг друга.
6. В «Решении» линия рисуется по скроллу, точки шагов загораются.
7. Счётчики результатов (25 %, 20 ч, 50+, 10+) с моноширинными цифрами.
8. Карточки услуг появляются каскадом, при наведении подсвечивается рамка.
9. Проекты на десктопе едут горизонтальной лентой на пине.
10. Кнопки CTA магнитятся к курсору, курсор кастомный (только для мыши).
11. Переходы между страницами закрываются фиолетовой шторой.

Анимируются только `transform` и `opacity` — layout shift исключён.

## Отличия от текущего сайта

- **Исправлена опечатка.** На старом сайте в разделе «О нас» написано
  «Люди, вдохновленные **врагами** и мудрецами» — очевидная ошибка перевода.
  В новой версии: «вдохновлённые **героями** и мудрецами». Если формулировка
  была намеренной, поправьте в `o-nas.html`.
- **Убран эмбед Mailchimp** с английскими подписями (`* indicates required`,
  `Email Address`) и логотипом Intuit прямо в вёрстке. Вместо него — своя форма
  с русскими подписями, маской узбекского телефона и понятными ошибками.
- **Только русский язык.** Переключатель Рус / Eng / Oʻzb в шапке оставлен,
  Eng и Oʻzb ведут на текущие страницы sherikkon.uz. Когда понадобятся
  переводы — структура к этому готова.
- **Детальных страниц проектов нет.** На `proekti.html` семь карточек-кейсов;
  отдельные страницы под каждый проект не верстались.
- **Карта не встроена.** На `kontakti.html` — адрес и кнопка «Открыть
  в Яндекс Картах», без сторонних скриптов и трекеров. Чтобы вставить живую
  карту: Яндекс Карты → «Поделиться» → «Встроить карту», и заменить блок
  в разделе «Как нас найти» на `<iframe class="map-frame">`.

## Технические заметки

- **Спрайт иконок инлайнится в каждую страницу.** Внешний `<use href="sprite.svg#id">`
  не работает при открытии по `file://` и капризничает в Safari. `assets/icons/sprite.svg`
  остаётся источником правды: правите его — переносите изменения в страницы.
- **Шрифты локальные.** Google Fonts не подгружается со стороны: нет внешних
  запросов, работает офлайн, ничего не отвалится при блокировках.
  Подключены кириллические и латинские сабсеты с `unicode-range`.
- **GSAP лежит в `assets/vendor/`**, а не на CDN — по той же причине.
- **Картинки взяты с текущего сайта** и оставлены в исходных JPEG/WebP.
  Конвертировать их в WebP было нечем (нет Node/Python на машине), поэтому
  от сдвигов вёрстки защищаемся через `aspect-ratio` на контейнерах
  плюс `loading="lazy"` и `decoding="async"`.

## Публикация

Папка полностью самодостаточна. Залейте её содержимое в корень хостинга —
или подключите к Netlify, Vercel, GitHub Pages, Cloudflare Pages без всякой
настройки сборки.

Перед публикацией:

1. Подключите `ENDPOINT` в `assets/js/forms.js` — иначе заявки будут теряться.
2. Проверьте текст про опечатку «героями / врагами» в `o-nas.html`.
3. При желании вставьте настоящую карту на `kontakti.html`.
4. `serve.ps1` на хостинг заливать не нужно — это только для локального просмотра.
